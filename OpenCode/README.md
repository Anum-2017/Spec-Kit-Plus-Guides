# 🪟 Important Windows Note

OpenCode's official documentation currently recommends **WSL for Windows** because it provides better performance and compatibility.

Other Windows installation methods include:

* npm
* Chocolatey
* Scoop
* Mise
* Docker
* Releases

Official OpenCode documentation: https://opencode.ai/docs
