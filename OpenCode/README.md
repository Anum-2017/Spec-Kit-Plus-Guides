# 🔄 Workflow

After setup:

```text
OpenCode
    ↓
Spec-Kit Plus
    ↓
/sp.constitution
    ↓
/sp.specify
    ↓
/sp.clarify
    ↓
/sp.plan
    ↓
/sp.tasks
    ↓
/sp.analyze
    ↓
/sp.implement
```
